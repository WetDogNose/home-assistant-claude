# Documentation

The Claude Terminal add-on documentation lives with the add-on:

**→ [claude-terminal/DOCS.md](claude-terminal/DOCS.md)**

That is the file Home Assistant renders on the add-on's *Documentation* tab,
and it is the only copy kept current. It covers installation, every
configuration option, terminal tips (scrolling and copy/paste), the Home
Assistant MCP integration, security notes, and troubleshooting.

Other entry points:

- [README.md](README.md) — repository overview and installation
- [claude-terminal/README.md](claude-terminal/README.md) — add-on overview and feature list
- [claude-terminal/CHANGELOG.md](claude-terminal/CHANGELOG.md) — release history
- [DEVELOPMENT.md](DEVELOPMENT.md) — local build and test workflows
- [CLAUDE.md](CLAUDE.md) — architecture and conventions for working on this repo

> This file previously held a second, diverged copy of the add-on
> documentation. It had drifted badly out of date — describing commands that
> do not exist and a storage path the add-on no longer uses — so it was
> replaced with this pointer rather than maintained in parallel.
